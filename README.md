# aiyong

爱用小组件移动端与内容运营中台交互原型。

浏览器直接打开根目录 `index.html` 即可使用，无需安装依赖。

## 最新内容

- 中台：栏目管理、桌面组件、App 总开关配置、铃声提示音。
- 能量搭配、我的组件、桌面安装与互动演示。
- 薪资计算、月历打卡、喝水打卡、听歌时钟、每日计划。
- 薪资每 10 分钟自动刷新，支持保密展示和下班倒计时；倒计时在详情与模拟桌面按秒更新。
- 到下班时间自动切换薪资组件样式，中台可分别配置下班后的背景、装饰层、提示文案和文字颜色。
- 4×4 桌宠小屋：切换房间与同一个娃娃的互动状态。
- 桌宠与自定义打卡预览上方提供灰色互动提示。
- 自定义打卡组件2：续火花示例，打卡前后分别配置背景、文案和文字颜色，展示累计打卡天数；旧自定义打卡组件已移除。
- 月历打卡：文字打卡按钮、内置方框配色、多图标切换与累计打卡记录。
- 喝水打卡：达到目标后自动切换完成图片和文案，支持 2×2、2×4。
- 同一组件参数码支持新增多套独立素材配置，以组件 ID 区分。
- 统一的字体颜色、背景与透明背景控件。

配置及演示数据保存在当前浏览器 localStorage 中。网页中的桌面安装为原型演示，不会实际安装到操作系统桌面。
