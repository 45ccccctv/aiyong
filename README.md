# aiyong

爱用小组件移动端与内容运营中台交互原型。

浏览器直接打开根目录 `index.html` 即可使用，无需安装依赖。

## 最新内容

- 中台：栏目管理、桌面组件、App 总开关配置、铃声提示音。
- 能量搭配、我的组件、桌面安装与互动演示。
- 薪资计算、自定义打卡、月历打卡、喝水打卡、听歌时钟、每日计划。
- 4×4 桌宠小屋：切换房间与同一个娃娃的互动状态。
- 自定义打卡组件2：续火花示例，打卡前后分别配置背景、文案和文字颜色，不显示天数。
- 统一的字体颜色、背景与透明背景控件。

配置及演示数据保存在当前浏览器 localStorage 中。网页中的桌面安装为原型演示，不会实际安装到操作系统桌面。
